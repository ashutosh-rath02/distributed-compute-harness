Revoked devices

Refused on every reconnect, even with the shared pairing token. Revocation denies one identity: a device that knows the shared pairing token can enroll a new one, so also restart the manager with a new -pairing-token to cut it off completely.

Use with AI apps

Apps that speak OpenAI's chat API (chat apps, editor plugins, scripts using the openai library) can use the AI models on your devices: give them this base URL and key. Each request runs on a device that has the model, like any task, and the answer streams back. The key opens only the chat API, nothing else. The API answers on this computer only. To replace the key, delete ai-key in the manager's state folder and restart the manager.

AI models on your devices

Each device keeps its own models in its own Ollama. Download one to the device that should run it (big models want a big GPU or lots of memory), or remove one to free its disk space. AI tasks go to a device that has the model, preferring one whose graphics card can hold it. A device shows here once Ollama runs on it.

A model too big for one device

Devices with llama.cpp installed can run one model together: the device with the model file (.gguf) runs it, the others lend their memory, connected through the manager (llama.cpp's helper has no password, so it never listens on your network). Chat with it through "Use with AI apps" by the name you give it. It stops when unused for 30 minutes, or when a device is unplugged or in use. Helpers keep the model pieces they were sent (HomeHarness\llama-rpc-cache in their cache folder) so the next start is quicker: delete that folder to free the space.

Ask for a job in plain words

A local AI model turns your words into a job made only of the built-in task types. The harness checks the plan and shows exactly what would run; nothing runs until you approve it.

Run a task

Typed tasks are built into every agent and run the same on every device, inside their own folder with only the files you give them.

Run a visible test

For CPU pulse, open the device's task manager / activity monitor before dispatching.

Advanced: raw command

The program runs inside its own folder holding the inputs, so run scripts through their interpreter. Outputs come back here to download.

Policy: what the fleet may run

Raw commands and host file reads run anything on a device: they stay off unless you turn them on, ideally only for devices you label (e.g. raw=ok in Rename/labels).
