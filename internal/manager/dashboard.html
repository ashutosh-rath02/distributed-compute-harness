Add a device

Another Windows desktop: keep it on the same Wi-Fi, enter this phone's current Wi-Fi address plus :7420, choose Windows, create a fresh QR/link, then open the full HTTPS link on that desktop. Accept the local certificate warning and run the displayed PowerShell command. Keep that agent process running.

The phone IP can change when Wi-Fi changes. Generate a new link with the new address, or use LAN discovery/a reserved DHCP address. Remote mode needs the separate public relay.

Not auto-detected on purpose — a multi-homed machine has no single "right" address to guess.

QR + link uses the relay's public HTTPS enrollment gateway and downloads automatically. The plain “Generate script” fallback still expects the matching binary to be placed on the device first.
