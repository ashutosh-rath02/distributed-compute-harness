Task types

Generated from the catalog the manager and agents are built with, so it is always what this version accepts. Every parameter value is sent as a string. Your operator policy decides which types are switched on (harnessctl policy).

  • archive.zip: Zip files together
  • audio.transcribe: Transcribe speech to text
  • container.run: Run a container
  • cpu.burn: CPU load test
  • doc.text: Get the text out of a PDF or picture
  • file.hash: Checksum files
  • image.resize: Resize an image
  • image.stack: Stack image strips
  • image.upscale: Upscale an image
  • llm.chat: Chat with a local AI model
  • llm.classify: Sort a text file into one of your labels
  • llm.embed: Embed text with a local AI model
  • llm.generate: Ask a local AI model
  • llm.inventory: List local AI models
  • llm.pull: Download a local AI model
  • llm.remove: Remove a local AI model
  • media.transcode: Convert a video or audio file
  • render.fractal: Render part of a fractal image
  • report.collect: Collect results into one report
  • system.identity: Device identity
  • text.count: Count lines and words

archive.zipcan combine results

Zip files together. Pack every input into one zip archive (by file name). Use it as a job's final step to get one download.

ParameterTypeRequiredDefaultMeaning and limits
namestringarchive.zipArchive name. pattern [A-Za-z0-9._-]{1,60}\.zip

Takes 1 to 256 input files. the files to pack

Result files: {{name}}.

audio.transcribestreams output

Transcribe speech to text. Write down what is said in a recording with whisper.cpp, on the device: transcript.txt and subtitles (transcript.srt). A .wav works anywhere it is offered; other audio and video files need ffmpeg on that device too. Offered by devices with whisper.cpp and a model.

ParameterTypeRequiredDefaultMeaning and limits
modelstringyesModel. up to 64 characters. pattern [A-Za-z0-9][A-Za-z0-9._-]{0,63}
languagestringautoSpoken language (auto, or a code like en, de, fr). pattern auto|[a-z]{2,3}

Takes exactly 1 input file(s). File types: wav, mp3, m4a, aac, flac, ogg, opus, wma, webm, mp4, m4v, mov, mkv. one recording

Result files: transcript.txt</code>, <code>transcript.srt.

container.runoff until policy enables itstreams output

Run a container. Run a container image with the device's own Docker or Podman: no network unless allowed, a read-only filesystem, no privileges, CPU, memory and process limits. Input files are at /in (read-only); the files it writes to /out that you name come back. Off until policy turns it on and allows the image.

ParameterTypeRequiredDefaultMeaning and limits
imagestringyesImage (pinned: name@sha256:...). up to 512 characters. pattern (?:(?:[a-zA-Z0-9]|[a-zA-Z0-9][a-zA-Z0-9-]*[a-zA-Z0-9])(?:\.(?:[a-zA-Z0-9]|[a-zA-Z0-9][a-zA-Z0-9-]*[a-zA-Z0-9]))*(?::[0-9]{1,5})?/)?[a-z0-9]+(?:(?:[._]|__|-+)[a-z0-9]+)*(?:/[a-z0-9]+(?:(?:[._]|__|-+)[a-z0-9]+)*)*(?::[A-Za-z0-9_][A-Za-z0-9_.-]{0,127})?(?:@sha256:[a-f0-9]{64})?
argsstringCommand as a JSON list, e.g. ["sh","-c","wc -l /in/*"] (empty = the image's own). up to 16384 characters
outputsstringFiles to bring back from /out (comma-separated). up to 2200 characters. pattern [A-Za-z0-9._/-]+(?:,[A-Za-z0-9._/-]+)*
cpusnumber1CPUs. at least 0.1. at most 64
memory_mbint512Memory limit (MB). at least 16. at most 65536
networkenumnoneNetwork. one of: none, bridge
timeoutint600Time limit (seconds). at least 1. at most 86400
platformstringPlatform, e.g. linux/arm64 (empty = any). up to 32 characters. pattern [a-z0-9]+/[a-z0-9_]+

Takes 0 to 256 input files. files for /in (read-only)

cpu.burn

CPU load test. Keep the device's CPUs busy for a while, to watch load move across the fleet.

ParameterTypeRequiredDefaultMeaning and limits
secondsint20Seconds. at least 1. at most 600
threadsint0Threads (0 = every CPU). at least 0. at most 256

Takes no input files.

doc.text

Get the text out of a PDF or picture. Write a PDF's or a scanned page's text to text.txt. text: the PDF's own text (poppler's pdftotext); ocr: recognize it in the picture or the PDF's pages (tesseract); auto: the PDF's text where it has some, recognition otherwise. Offered by devices with pdftotext or tesseract.

ParameterTypeRequiredDefaultMeaning and limits
methodenumautoHow to read it. one of: auto, text, ocr
languagestringengLanguage for recognition (e.g. eng, deu, eng+fra). pattern [a-z]{3}(_[a-z]{3,4})?(\+[a-z]{3}(_[a-z]{3,4})?){0,3}

Takes exactly 1 input file(s). File types: pdf, png, jpg, jpeg. one PDF or picture

Result files: text.txt.

file.hashcan combine results

Checksum files. Write a checksum line for every input to hashes.txt.

ParameterTypeRequiredDefaultMeaning and limits
algorithmenumsha256Algorithm. one of: sha256, sha1, md5

Takes 1 to 256 input files. the files to checksum

Result files: hashes.txt.

image.resize

Resize an image. Scale a JPEG, PNG or GIF to a new width (height follows the aspect ratio unless given). Run it once per photo as a job to spread a batch over the fleet.

ParameterTypeRequiredDefaultMeaning and limits
widthintyes1024Width (pixels). at least 1. at most 10000
heightint0Height (0 = keep aspect). at least 0. at most 10000
formatenumjpgOutput format. one of: jpg, png
qualityint85JPEG quality. at least 1. at most 100

Takes exactly 1 input file(s). File types: jpg, jpeg, png, gif. one image

Result files: {{in.stem}}-{{width}}.{{format}}.

image.stackcan combine results

Stack image strips. Join images top to bottom, in name order, into one PNG: the last step of a job that renders a picture in strips.

ParameterTypeRequiredDefaultMeaning and limits
namestringimage.pngResult name. pattern [A-Za-z0-9._-]{1,60}\.png

Takes 1 to 256 input files. File types: png, jpg, jpeg, gif. the strips, top first by name

Result files: {{name}}.

image.upscale

Upscale an image. Enlarge a JPEG, PNG or GIF 2, 3 or 4 times with a smooth, sharp resampler (Catmull-Rom). The result may have at most 40 million pixels.

ParameterTypeRequiredDefaultMeaning and limits
scaleint2Scale (times). at least 2. at most 4
formatenumpngOutput format. one of: png, jpg
qualityint92JPEG quality. at least 1. at most 100

Takes exactly 1 input file(s). File types: jpg, jpeg, png, gif. one image

Result files: {{in.stem}}-x{{scale}}.{{format}}.

llm.chatstreams output

Chat with a local AI model. One turn of a conversation with a local model (Ollama) on whichever device has it: the messages so far in, the reply streamed back. What AI apps use through the manager's OpenAI-compatible API (/v1).

ParameterTypeRequiredDefaultMeaning and limits
modelstringyesModel. up to 128 characters. pattern [A-Za-z0-9][A-Za-z0-9._:/-]{0,127}
messagesstringyesMessages (JSON: [{role, content}]). up to 65536 characters
temperaturenumberTemperature (empty = the model's default). at least 0. at most 2
max_tokensintMax tokens (empty = no limit). at least 1. at most 131072
seedint0Seed (0 = random). at least 0. at most 2.147483647e+09
formatstringAnswer format (empty = free text; json, or a JSON schema). up to 16384 characters

Takes no input files.

Result files: response.txt.

llm.classify

Sort a text file into one of your labels. A local AI model (Ollama) reads one text file and picks the one label that fits it best from yours (e.g. invoice, receipt, letter); writes label.json. Run it once per file as a job and collect the labels into one table with report.collect.

ParameterTypeRequiredDefaultMeaning and limits
modelstringyesModel. up to 128 characters. pattern [A-Za-z0-9][A-Za-z0-9._:/-]{0,127}
labelsstringyesLabels (2-32, separated by commas). up to 2048 characters

Takes exactly 1 input file(s). one text file (UTF-8, at most 32 KiB)

Result files: label.json.

llm.embedstreams output

Embed text with a local AI model. Turn text files into embeddings: lists of numbers that place texts with similar meaning close together, for search and grouping. Needs an embedding model (Ollama, e.g. embeddinggemma or nomic-embed-text) on some device; writes embeddings.json. Each file must fit the model's context.

ParameterTypeRequiredDefaultMeaning and limits
modelstringyesEmbedding model. up to 128 characters. pattern [A-Za-z0-9][A-Za-z0-9._:/-]{0,127}

Takes 1 to 16 input files. text files (UTF-8, at most 32 KiB each)

Result files: embeddings.json.

llm.generatestreams output

Ask a local AI model. Run a prompt on a local model (Ollama) on whichever device has it, streaming the answer back. Text files given as input are included as context.

ParameterTypeRequiredDefaultMeaning and limits
modelstringyesModel. up to 128 characters. pattern [A-Za-z0-9][A-Za-z0-9._:/-]{0,127}
promptstringyesPrompt. up to 16384 characters
systemstringSystem instructions (optional). up to 4096 characters
temperaturenumber0.7Temperature. at least 0. at most 2
max_tokensint512Max tokens. at least 1. at most 8192
seedint0Seed (0 = random). at least 0. at most 2.147483647e+09

Takes 0 to 16 input files. text files to use as context (at most 32 KiB together)

Result files: response.txt.

media.transcode

Convert a video or audio file. Convert with ffmpeg to a fixed preset: 720p.mp4 or 1080p.mp4 (H.264 video, never enlarged), audio.mp3, audio.m4a, or clip.gif (a short animated GIF, at most 30 seconds). Optionally only a part: start and length in seconds. Offered by devices that have ffmpeg.

ParameterTypeRequiredDefaultMeaning and limits
presetenum720p.mp4Convert to. one of: 720p.mp4, 1080p.mp4, audio.mp3, audio.m4a, clip.gif
startint0Start at (seconds). at least 0. at most 86400
durationint0Length (seconds, 0 = to the end; a GIF: 10). at least 0. at most 14400

Takes exactly 1 input file(s). File types: mp4, m4v, mov, mkv, webm, avi, mpg, mpeg, ts, mts, m2ts, flv, wmv, 3gp, gif, mp3, m4a, aac, wav, flac, ogg, opus, wma. one video or audio file

Result files: {{in.stem}}-{{preset}}.

render.fractalruns in parts

Render part of a fractal image. Draw one horizontal strip of a Mandelbrot fractal, using every CPU core. Split a big image into many parts as a job and every device renders strips; image.stack joins them into one picture.

ParameterTypeRequiredDefaultMeaning and limits
widthint3200Image width (pixels). at least 16. at most 8000
heightint2400Image height (pixels). at least 16. at most 8000
partint0Which strip (0 = top). at least 0. at most 999
partsint1Strips in the whole image. at least 1. at most 1000
iterationsint2000Detail (iterations). at least 16. at most 50000
sceneenumseahorseWhere to look. one of: seahorse, spiral, classic

Takes no input files.

Result files: fractal-{{part}}.png.

report.collectcan combine results

Collect results into one report. Join a job's per-file results into one file, by the file each came from: answers and summaries (.txt), labels (label.json) and embeddings (embeddings.json). The report's extension picks the format: .md (Markdown), .csv (a table) or .json; embeddings join into .json only. Use it as the combine step of a per-file AI job.

ParameterTypeRequiredDefaultMeaning and limits
namestringreport.mdReport file (.md, .csv or .json). pattern [A-Za-z0-9._-]{1,60}\.(md|csv|json)

Takes 1 to 256 input files. File types: txt, md, json. per-file results: .txt answers, label.json, embeddings.json

Result files: {{name}}.

system.identity

Device identity. Report the device's hostname, OS, architecture and CPU count. A quick check that a device runs work.

No parameters.

Takes no input files.
