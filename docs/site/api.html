HTTP API

The manager's operator API is described in openapi.yaml (OpenAPI 3.1): every route, its request and response shapes, and how it authenticates. A test fails the build if a route exists that the file does not describe. This page lists the routes from that file.

Every route needs Authorization: Bearer <operator token>, except a few public ones noted in the file; the /v1 routes also accept the AI key. Most errors are a short plain-text message that says what to do next.
